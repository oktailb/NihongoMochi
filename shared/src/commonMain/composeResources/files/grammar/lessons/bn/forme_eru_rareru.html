সম্ভাব্য ফর্ম (可能形) - "করতে পারে"

The সম্ভাব্য ফর্ম is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. কিভাবে কনজুগেট করা যায়

গ্রুপ 1: U-ক্রিয়াপদ (গোদান)

Change the final "তুমি" sound to the "ই" sound and add る (রু).

  • 行く (iku - go) → 行け + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

গ্রুপ 2: রু-ক্রিয়া (ইচিদান)

Replace the final る (রু) with られる (বিরল).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

দ্রষ্টব্য: নৈমিত্তিক বক্তৃতায়, "রা" প্রায়ই বাদ দেওয়া হয়: 食べれる (তাবেরু)।

গ্রুপ 3: অনিয়মিত ক্রিয়া

  • する (suru) → できる (dekiru) - Can do (সম্পূর্ণ আলাদা!)
  • 来る (kuru) → 来られる (korareru) - Can come

2. গুরুত্বপূর্ণ কণা পরিবর্তন

When using the potential form, the object particle を (wo) often changes to が (গা).

  • 日本語を話します.(আমি জাপানি ভাষায় কথা বলি।)
  • 日本語が話せます。(I পারে speak Japanese.)

3. "সম্ভাব্য ফর্ম" বনাম "~কোতো গা দেকিরু"

Both mean "can do", but the potential form is more common in daily conversation, while koto ga dekiru is slightly more formal or used for long verb phrases.
