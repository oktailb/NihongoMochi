দ্য -তারা শর্তসাপেক্ষ (~たら)

The ~ তারা conditional is the most common and versatile way to say "if" or "when" in Japanese. It is used to describe a condition that must be met before another action can happen.

1. কিভাবে কনজুগেট করা যায়

The rule is simple: Take the তা-রূপ (informal past) of a verb, adjective, or noun, and add ら (রহ.).

ক্রিয়াপদ

  • 行く (iku - to go) → 行った (itta) → 行ったら (ittara) - If I go / When I go
  • 食べる (taberu - to eat) → 食べた (tabeta) → 食べたら (tabetara) - If I eat / When I eat
  • する (suru - to do) → した (shita) → したら (shitara) - If I do

বিশেষণ

  • আমি-বিশেষণ: Replace the final ~i with ~কাত্তারা.
    安い (yasui - cheap) → 安かったら (yasukattara) - If it is cheap.
  • না-বিশেষণ: Add ~ দত্তরা.
    暇 (hima - free time) → 暇だったら (hima dattara) - If you are free.

বিশেষ্য

Like Na-adjectives, add ~ দত্তরা.

  • 雨 (ame - rain) → 雨だったら (ame dattara) - If it rains.

2. কখন এটি ব্যবহার করবেন?

  1. অনুমানমূলক "যদি": When something might happen.
    お金があったら、車を買います。(Okane ga attara, kuruma wo kaimasu) - If I had money, I would buy a car.
  2. অস্থায়ী "কখন": When the condition is certain to happen in the future.
    家に着いたら、電話して。(Ie ni tsuitara, denwa shite) - When you get home, call me.

3. গুরুত্বপূর্ণ নোট

The event in the ~ তারা clause must happen প্রথম. You cannot use ~ তারা for things happening at the same time.
