Най-форма (ない形) – неформальный негатив

The Най-форма is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. Как конъюгировать

Спряжение зависит от группы глаголов. Обратите особое внимание на группу 1!

Группа 1: У-глаголы (Годан)

Change the final "ты" sound of the dictionary form to the corresponding "а" sound, then add ない.

  • 書く (kaku) → 書か + ない = 書かない (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 飲まない (nomanai) - Not drink
  • 話す (hanasu) → 話さ + ない = 話さない (hanasanai) - Not speak

⚠️Особое правило: If the verb ends in a plain う (ты), it changes to わ (ва), not 'a'.

  • 買う (kau) → 買わ + ない = 買わない (kawanai) - Not buy

Группа 2: Ру-глаголы (Ичидан)

Simply drop the final る (ру) and add ない.

  • 食べる (taberu) → 食べない (tabenai) - Not eat
  • 見る (miru) → 見ない (minai) - Not see

Группа 3: Неправильные глаголы

Внимательно запомните их (обратите внимание на изменение звука слова «куру»):

  • する (suru) → しない (shinai)
  • 来る (kuru) → 来ない (konai - pronounced ко-най)
  • ある (aru - to exist/have) → ない (nai) (Совершенно ненормально!)

2. Общие грамматические шаблоны

Форма Най необходима для следующих основных структур:

  1. Просит ничего не делать (~найде кудасай):
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. Обязательство (~накереба наримасен): "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. Делать что-то, не делая другого (~zuni/~naide):
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
