Потенциальная форма (可能形) — «Могу сделать».

The Потенциальная форма is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. Как конъюгировать

Группа 1: У-глаголы (Годан)

Change the final "ты" sound to the "е" sound and add る (ру).

  • 行く (iku - go) → 行け + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

Группа 2: Ру-глаголы (Ичидан)

Replace the final る (ру) with られる (редко).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

Примечание. В повседневной речи буква «ра» часто встречается: 食べれる (табереру).

Группа 3: Неправильные глаголы

  • する (suru) → できる (dekiru) - Can do (Совсем другое!)
  • 来る (kuru) → 来られる (korareru) - Can come

2. Важное изменение частиц

When using the potential form, the object particle を (во) often changes to が (га).

  • 日本語を話します。 (Я говорю по-японски.)
  • 日本語が話せます。(I может speak Japanese.)

3. «Потенциальная форма» vs «~кото га декиру»

Both mean "can do", but the potential form is more common in daily conversation, while Кото Га Декиру is slightly more formal or used for long verb phrases.
