تارا الشرطية (~たら)

The ~ تارا conditional is the most common and versatile way to say "if" or "when" in Japanese. It is used to describe a condition that must be met before another action can happen.

1. كيفية الاقتران

The rule is simple: Take the شكل تا (informal past) of a verb, adjective, or noun, and add ら (رع).

أفعال

  • 行く (iku - to go) → 行った (itta) → نعم (ittara) - If I go / When I go
  • 食べる (taberu - to eat) → 食べた (tabeta) → هذا هو (tabetara) - If I eat / When I eat
  • する (suru - to do) → した (shita) → نعم (shitara) - If I do

الصفات

  • أنا- الصفات: Replace the final ~i with ~ كتارا.
    安い (yasui - cheap) → شكرا جزيلا (yasukattara) - If it is cheap.
  • نا الصفات: Add ~ داتارا.
    暇 (hima - free time) → شكرا جزيلا (hima dattara) - If you are free.

الأسماء

Like Na-adjectives, add ~ داتارا.

  • 雨 (ame - rain) → هذا هو الحال (ame dattara) - If it rains.

2. متى يتم استخدامه؟

  1. افتراضية "إذا": When something might happen.
    お金があったら、車を買います。(Okane ga attara, kuruma wo kaimasu) - If I had money, I would buy a car.
  2. "متى" المؤقتة: When the condition is certain to happen in the future.
    家に着いたら、電話して。(Ie ni tsuitara, denwa shite) - When you get home, call me.

3. ملاحظة هامة

The event in the ~ تارا clause must happen أولاً. You cannot use ~ تارا for things happening at the same time.
