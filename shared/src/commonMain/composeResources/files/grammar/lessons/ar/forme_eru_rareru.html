النموذج المحتمل (可能形) - "يمكن أن أفعل"

The النموذج المحتمل is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. كيفية الاقتران

المجموعة 1: أفعال U (غودان)

Change the final "أنت" sound to the "ه" sound and add る (رو).

  • 行く (iku - go) → 行け + る = نعم (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = هذا هو (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

المجموعة 2: أفعال رو (إيشيدان)

Replace the final る (رو) with られる (نادر).

  • 食べる (taberu) → 食 べ ら れ る (taberareru) - Can eat
  • 見る (miru) → مثلا (mirareru) - Can see

ملاحظة: في الكلام غير الرسمي، غالبًا ما يتم إسقاط "ra": 食べれる (tabereru).

المجموعة 3: الأفعال الشاذة

  • する (suru) → できる (dekiru) - Can do (مختلفة تماما!)
  • 来る (kuru) → られる (korareru) - Can come

2. تغيير الجسيمات المهم

When using the potential form, the object particle を (وو) often changes to が (جا).

  • 日本語を話します.(أنا أتحدث اليابانية.)
  • 日本語が話せます。(I يستطيع speak Japanese.)

3. "النموذج المحتمل" مقابل "~koto ga dekiru"

Both mean "can do", but the potential form is more common in daily conversation, while كوتو جا ديكيرو is slightly more formal or used for long verb phrases.
