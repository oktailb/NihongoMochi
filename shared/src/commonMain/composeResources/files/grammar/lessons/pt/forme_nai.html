A forma Nai (ない形) - Negativo Informal

The Forma Nai is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. Como conjugar

A conjugação depende do grupo verbal. Preste muita atenção ao Grupo 1!

Grupo 1: Verbos U (Godan)

Change the final "você" sound of the dictionary form to the corresponding "um" sound, then add ない.

  • 書く (kaku) → 書か + ない = 書かない (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 飲まない (nomanai) - Not drink
  • 話す (hanasu) → 話さ + ない = 話さない (hanasanai) - Not speak

⚠️ Regra Especial: If the verb ends in a plain う (você), it changes to わ (wa), not 'a'.

  • 買う (kau) → 買わ + ない = 買わない (kawanai) - Not buy

Grupo 2: Ru-Verbos (Ichidan)

Simply drop the final る (ru) and add ない.

  • 食べる (taberu) → 食べない (tabenai) - Not eat
  • 見る (miru) → 見ない (minai) - Not see

Grupo 3: Verbos Irregulares

Memorize-os cuidadosamente (observe a mudança de som para 'kuru'):

  • する (suru) → しない (shinai)
  • 来る (kuru) → 来ない (konai - pronounced ko-nai)
  • ある (aru - to exist/have) → ない (nai) (Completamente irregular!)

2. Padrões gramaticais comuns

O formulário Nai é necessário para estas estruturas essenciais:

  1. Solicitações para não fazer algo (~naide kudasai):
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. Obrigação (~nakereba narimasen): "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. Fazer algo sem fazer outro (~zuni / ~naide):
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
