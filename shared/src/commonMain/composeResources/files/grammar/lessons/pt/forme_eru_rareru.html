A Forma Potencial (可能形) - "Pode fazer"

The Formulário Potencial is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. Como conjugar

Grupo 1: Verbos U (Godan)

Change the final "você" sound to the "e" sound and add る (ru).

  • 行く (iku - go) → 行け + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

Grupo 2: Ru-Verbos (Ichidan)

Replace the final る (ru) with られる (rareru).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

Nota: Na linguagem casual, o "ra" é frequentemente omitido: 食べれる (tabereru).

Grupo 3: Verbos Irregulares

  • する (suru) → できる (dekiru) - Can do (Completamente diferente!)
  • 来る (kuru) → 来られる (korareru) - Can come

2. Mudança importante de partículas

When using the potential form, the object particle を (ai) often changes to が (ga).

  • 日本語を話します。(Eu falo japonês.)
  • 日本語が話せます。(I pode speak Japanese.)

3. "Forma Potencial" vs "~koto ga dekiru"

Both mean "can do", but the potential form is more common in daily conversation, while koto ga dekiru is slightly more formal or used for long verb phrases.
