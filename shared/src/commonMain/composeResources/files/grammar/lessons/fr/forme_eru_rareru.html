La forme potentielle (可能形) - "Peut faire"

The Forme potentielle is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. Comment conjuguer

Groupe 1 : Verbes U (Godan)

Change the final "tu" sound to the "e" sound and add る (ru).

  • 行く (iku - go) → 行· + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

Groupe 2 : Verbes Ru (Ichidan)

Replace the final る (ru) with られる (rareru).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

Remarque : Dans le langage courant, le « ra » est souvent abandonné : 食べれる (tabereru).

Groupe 3 : Verbes irréguliers

  • する (suru) → できる (dekiru) - Can do (Complètement différent !)
  • 来る (kuru) → 来られる (korareru) - Can come

2. Changement important de particules

When using the potential form, the object particle を (wo) often changes to が (ga).

  • 日本語を話します。(Je parle japonais.)
  • 日本語が話せます。(I peut speak Japanese.)

3. « Forme potentielle » contre « ~koto ga dekiru »

Both mean "can do", but the potential form is more common in daily conversation, while koto ga dekiru is slightly more formal or used for long verb phrases.
