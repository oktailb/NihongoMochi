La forme Nai (ない形) - Négatif informel

The Forme Nai is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. Comment conjuguer

La conjugaison dépend du groupe de verbes. Soyez très attentif au groupe 1 !

Groupe 1 : Verbes U (Godan)

Change the final "tu" sound of the dictionary form to the corresponding "un" sound, then add ない.

  • 書く (kaku) → 書か + ない = 書かない (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 飲まない (nomanai) - Not drink
  • 話す (hanasu) → 話さ + ない = 話さない (hanasanai) - Not speak

⚠️ Règle spéciale : If the verb ends in a plain う (tu), it changes to わ (wa), not 'a'.

  • 買· (kau) → 買わ + ない = 買わない (kawanai) - Not buy

Groupe 2 : Verbes Ru (Ichidan)

Simply drop the final る (ru) and add ない.

  • 食べる (taberu) → 食べない (tabenai) - Not eat
  • 見る (miru) → 見ない (minai) - Not see

Groupe 3 : Verbes irréguliers

Mémorisez-les soigneusement (notez le changement de son pour « kuru ») :

  • する (suru) → しない (shinai)
  • 来る (kuru) → 来ない (konai - pronounced ko-nai)
  • ある (aru - to exist/have) → ない (nai) (Complètement irrégulier !)

2. Modèles de grammaire courants

La forme Nai est requise pour ces structures essentielles :

  1. Demandes de ne pas faire quelque chose (~naide kudasai) :
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. Obligation (~nakereba narimasen) : "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. Faire quelque chose sans en faire un autre (~zuni / ~naide) :
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
