Particules de base (助詞 - Joshi)

Les particules sont de petits marqueurs qui suivent les mots pour indiquer leur rôle dans une phrase. Ils sont la « colle » qui maintient les phrases japonaises ensemble.

1. Le marqueur de sujet : は (wa)

La particuleは(écrit « ha » mais prononcé « wa ») identifie lesujetde la phrase – de quoi vous parlez.

  • 私は学生です。(WatashiWashingtongakusei desu) -Quant à moi, je suis étudiant.

2. Le marqueur de sujet : が (ga)

Alors queはmarque le sujet,がmarque lesujet spécifiquequi accomplit une action ou possède une qualité. Il fournit souvent de nouvelles informations.

  • 猫が好きです。(NekoGéorgiesuki desu) - J'aime les chats (lit : Les chats sont sympathiques).
  • だれが来ましたか？ (OsezGéorgieKimashita Ka?) -OMSest venu?

3. Le marqueur d'objet : を (wo)

La particuleを(prononcé « o ») marque leobjet direct- la chose sur laquelle agit un verbe.

  • リンゴを食べます。(Ringohélastabemasu) - je mangeune pomme.

4. Le marqueur de destination/temps : に (ni)

Cette particule polyvalente indiquedirection, heure précise, ouemplacement(d'existence).

  • 日本に行きます。(Nihonniikimasu) - j'y vaisàJapon.
  • 八時に起きます。(Hachijiniokimasu) - je me réveilleà8 heures.

5. Le lieu de l'action : で (de)

Indiqueoùune action a lieu, ou lemoyen/outilj'avais l'habitude de faire quelque chose.

  • 学校で勉強します。(Gakkoudebenkyou shimasu) - J'étudieàécole.
  • ペンで書きます。(Stylodekakimasu) - j'écrisavecun stylo.

6. Le marqueur Possession/Relation : の (non)

Indiquepossessionou relie deux noms. Cela fonctionne comme "'s" en anglais.

  • 私の本 (WatashiNonchérie) -Monlivre.
  • 日本語の先生 (NihongoNonSensei) -japonaisprofesseur.
