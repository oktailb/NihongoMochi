Най-хэлбэр (ない形) - Албан бус сөрөг

The Най-хэлбэр is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. Хэрхэн нийлүүлэх вэ

Холболт нь үйл үгийн бүлгээс хамаардаг. 1-р бүлэгт анхаарлаа хандуулаарай!

1-р бүлэг: U-үйл үгс (Годан)

Change the final "у" sound of the dictionary form to the corresponding "а" sound, then add ない.

  • 書く (kaku) → 書か + ない = 書かない (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 飲まない (nomanai) - Not drink
  • 話す (hanasu) → 話さ + ない = 話さない (hanasanai) - Not speak

⚠️ Тусгай дүрэм: If the verb ends in a plain う (у), it changes to わ (wa), not 'a'.

  • 買う (kau) → 買わ + ない = 買わない (kawanai) - Not buy

2-р бүлэг: Ру-Үйл үгс (Ичидан)

Simply drop the final る (ру) and add ない.

  • 食べる (taberu) → 食べない (tabenai) - Not eat
  • 見る (miru) → 見ない (minai) - Not see

3-р бүлэг: Тогтмол бус үйл үг

Эдгээрийг анхааралтай цээжил ("куру"-ны дууны өөрчлөлтийг анхаарна уу):

  • する (suru) → しない (shinai)
  • 来る (kuru) → 来ない (konai - pronounced ко-най)
  • ある (aru - to exist/have) → ない (nai) (Бүрэн жигд бус!)

2. Дүрмийн нийтлэг хэв маяг

Эдгээр чухал бүтцэд Nai хэлбэр шаардлагатай:

  1. Ямар нэг зүйл хийхгүй байхыг хүсэх (~naide kudasai):
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. Үүрэг (~nakereba narimasen): "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. Өөр хийхгүйгээр ямар нэг зүйл хийх (~zuni / ~naide):
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
