Боломжит хэлбэр (可能形) - "Чадна"

The Боломжит хэлбэр is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. Хэрхэн нийлүүлэх вэ

1-р бүлэг: U-үйл үгс (Годан)

Change the final "у" sound to the "e" sound and add る (ру).

  • 行く (iku - go) → 行け + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

2-р бүлэг: Ру-Үйл үгс (Ичидан)

Replace the final る (ру) with られる (ховор).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

Тайлбар: Энгийн ярианд "ra" нь тусгай зөвшөөрөл: 食べれる (tabereru).

3-р бүлэг: Тогтмол бус үйл үг

  • する (suru) → できる (dekiru) - Can do (Бүрэн өөр!)
  • 来る (kuru) → 来られる (korareru) - Can come

2. Бөөмийн чухал өөрчлөлт

When using the potential form, the object particle を (wo) often changes to が (га).

  • 日本を話します。(Би Япон хэлээр ярьдаг.)
  • 日本語が話せます。(I чадна speak Japanese.)

3. "Потенциал хэлбэр" vs "~кото га декру"

Both mean "can do", but the potential form is more common in daily conversation, while кото га декиру is slightly more formal or used for long verb phrases.
