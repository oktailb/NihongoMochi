Nai형(ない형) - 비공식 부정어

The 나이형 is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. 활용방법

활용은 동사 그룹에 따라 다릅니다. 그룹 1을 주의 깊게 살펴보세요!

그룹 1: U-동사(Godan)

Change the final "유" sound of the dictionary form to the corresponding "에이" sound, then add 그렇지 않다.

  • 書KU (kaku) → 書? + ない = 서 있거나 그렇지 (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 안돼요 (nomanai) - Not drink
  • 話스와 (hanasu) → 話사 + ない = 말도 안돼 (hanasanai) - Not speak

⚠️ 특별 규칙: If the verb ends in a plain 우(u), it changes to 와(와), not 'a'.

  • 買우 (kau) → 買わ + ない = 말도 안돼 (kawanai) - Not buy

그룹 2: Ru-동사(Ichidan)

Simply drop the final 루(루) and add 그렇지 않다.

  • 食べ루 (taberu) → 먹을 수 없어 (tabenai) - Not eat
  • 見루 (miru) → 아니 (minai) - Not see

그룹 3: 불규칙 동사

다음 사항을 주의 깊게 기억하세요('쿠루'의 소리 변화에 유의하세요).

  • 스는 (suru) → 그렇지 않다 (shinai)
  • 来루 (kuru) → 안돼 (konai - pronounced 코나이)
  • あRU (aru - to exist/have) → 그렇지 않다 (nai) (완전 불규칙해요!)

2. 일반적인 문법 패턴

Nai 형식은 다음과 같은 필수 구조에 필요합니다.

  1. 어떤 일도 하지 말아달라는 요청(~naide kudasai):
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. 의무(~nakereba narimasen): "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. 다른 일을 하지 않고 어떤 일을 하는 것(~zuni / ~naide):
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
