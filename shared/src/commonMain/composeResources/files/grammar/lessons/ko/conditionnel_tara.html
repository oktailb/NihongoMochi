-Tara 조건부(~たた)

The ~타라 conditional is the most common and versatile way to say "if" or "when" in Japanese. It is used to describe a condition that must be met before another action can happen.

1. 활용방법

The rule is simple: Take the 타형 (informal past) of a verb, adjective, or noun, and add 라(라).

동사

  • 行く (iku - to go) → 行った (itta) → 行たた (ittara) - If I go / When I go
  • 食べる (taberu - to eat) → 食べた (tabeta) → 음식베타라 (tabetara) - If I eat / When I eat
  • する (suru - to do) → した (shita) → 샤타라 (shitara) - If I do

형용사

  • I-형용사: Replace the final ~i with ~카타라.
    安い (yasui - cheap) → 안가타라 (yasukattara) - If it is cheap.
  • Na-형용사: Add ~다따라.
    暇 (hima - free time) → 暇다르다 (hima dattara) - If you are free.

명사

Like Na-adjectives, add ~다따라.

  • 雨 (ame - rain) → 雨다르다 (ame dattara) - If it rains.

2. 언제 사용하나요?

  1. 가상의 "만약": When something might happen.
    お金があったら、車を買います。(Okane ga attara, kuruma wo kaimasu) - If I had money, I would buy a car.
  2. 일시적인 "언제": When the condition is certain to happen in the future.
    家に着いたら、電話して。(Ie ni tsuitara, denwa shite) - When you get home, call me.

3. 중요사항

The event in the ~타라 clause must happen 첫 번째. You cannot use ~타라 for things happening at the same time.
