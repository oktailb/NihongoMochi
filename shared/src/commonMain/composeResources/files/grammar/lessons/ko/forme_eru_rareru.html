잠재적 형태(可能字) - "할 수 있다"

The 잠재적인 형태 is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. 활용방법

그룹 1: U-동사(Godan)

Change the final "유" sound to the "이자형" sound and add 루(루).

  • 行く (iku - go) → 行け + る = 行けRU (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 설명하다 (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲め루 (nomeru) - Can drink

그룹 2: Ru-동사(Ichidan)

Replace the final 루(루) with 라레루(rareru).

  • 食べる (taberu) → 식베라루 (taberareru) - Can eat
  • 見る (miru) → 살펴보자 (mirareru) - Can see

참고: 일상적인 대화에서는 "ra"가 자주 발생합니다: 식베레루(타베레루).

그룹 3: 불규칙 동사

  • する (suru) → 데키루 (dekiru) - Can do (완전히 다릅니다!)
  • 来る (kuru) → 来라레루 (korareru) - Can come

2. 중요한 입자 변화

When using the potential form, the object particle を(워) often changes to 가(가).

  • 日本語を話しまс。(저는 일본어를 합니다.)
  • 日本語が話せます。(I ~할 수 있다 speak Japanese.)

3. "잠재적 형태" vs "~koto ga dekiru"

Both mean "can do", but the potential form is more common in daily conversation, while 코토가 데키루 is slightly more formal or used for long verb phrases.
