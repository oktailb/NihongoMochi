La Forma Potenziale (可能形) - "Si può fare"

The Forma potenziale is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. Come coniugare

Gruppo 1: Verbi in U (Godan)

Change the final "tu" sound to the "e" sound and add る (ru).

  • 行く (iku - go) → 行け + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

Gruppo 2: Verbi Ru (Ichidan)

Replace the final る (ru) with られる (rareru).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

Nota: nel linguaggio informale, la "ra" viene spesso omessa: 食べれる (tabereru).

Gruppo 3: Verbi irregolari

  • する (suru) → できる (dekiru) - Can do (Completamente diverso!)
  • 来る (kuru) → 来られる (korareru) - Can come

2. Importante cambiamento delle particelle

When using the potential form, the object particle を (wo) often changes to が (ga).

  • 日本語を話します。(Parlo giapponese.)
  • 日本語が話せます。(I Potere speak Japanese.)

3. "Forma potenziale" vs "~koto ga dekiru"

Both mean "can do", but the potential form is more common in daily conversation, while koto ga dekiru is slightly more formal or used for long verb phrases.
