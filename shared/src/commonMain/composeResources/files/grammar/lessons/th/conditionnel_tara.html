เงื่อนไข -Tara (~ たら)

The ~ธารา conditional is the most common and versatile way to say "if" or "when" in Japanese. It is used to describe a condition that must be met before another action can happen.

1. วิธีการผันคำกริยา

The rule is simple: Take the ตา-ฟอร์ม (informal past) of a verb, adjective, or noun, and add ら (ระ).

กริยา

  • 行く (iku - to go) → 行った (itta) → 行ったら (ittara) - If I go / When I go
  • 食べる (taberu - to eat) → 食べた (tabeta) → รับประทานอาหาร (tabetara) - If I eat / When I eat
  • する (suru - to do) → した (shita) → ชิตะら (shitara) - If I do

คำคุณศัพท์

  • I-คำคุณศัพท์: Replace the final ~i with ~คัตทารา.
    安い (yasui - cheap) → 安かったら (yasukattara) - If it is cheap.
  • Na-คำคุณศัพท์: Add ~ดาททารา.
    暇 (hima - free time) → 暇だったら (hima dattara) - If you are free.

คำนาม

Like Na-adjectives, add ~ดาททารา.

  • 雨 (ame - rain) → 雨だったら (ame dattara) - If it rains.

2. ควรใช้เมื่อใด?

  1. สมมุติฐาน "ถ้า": When something might happen.
    お金があったら、車を買います。(Okane ga attara, kuruma wo kaimasu) - If I had money, I would buy a car.
  2. ชั่วคราว "เมื่อ": When the condition is certain to happen in the future.
    家に着いたら、電話して。(Ie ni tsuitara, denwa shite) - When you get home, call me.

3. หมายเหตุสำคัญ

The event in the ~ธารา clause must happen อันดับแรก. You cannot use ~ธารา for things happening at the same time.
