แบบฟอร์มศักยภาพ (可能形) - "ทำได้"

The แบบฟอร์มที่มีศักยภาพ is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. วิธีการผันคำกริยา

กลุ่มที่ 1: U-กริยา (Godan)

Change the final "คุณ" sound to the "อี" sound and add รู (รู).

  • 行く (iku - go) → 行け + る = 行けRU (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せRU (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲めRU (nomeru) - Can drink

กลุ่มที่ 2: Ru-กริยา (อิจิดัน)

Replace the final รู (รู) with られru (ราเรรุ).

  • 食べる (taberu) → รับประทานอาหาร (taberareru) - Can eat
  • 見る (miru) → 見られRU (mirareru) - Can see

หมายเหตุ: ในเนื้อหาทั่วไปคำว่า "ra" อาจถูกทิ้ง: ในกรณีนี้ べれる (tabereru)

กลุ่มที่ 3: กริยาที่ไม่สม่ำเสมอ

  • する (suru) → でคิรุ (dekiru) - Can do (แตกต่างอย่างสิ้นเชิง!)
  • 来る (kuru) → 来られRU (korareru) - Can come

2. การเปลี่ยนแปลงอนุภาคที่สำคัญ

When using the potential form, the object particle を (วอ) often changes to が (กา).

  • 日本語を話しまし。(ฉันพูดภาษาญี่ปุ่น)
  • 日本語が話せます。(I สามารถ speak Japanese.)

3. "รูปแบบที่เป็นไปได้" vs "~koto ga dekiru"

Both mean "can do", but the potential form is more common in daily conversation, while โคโตะ กา เดกิรุ is slightly more formal or used for long verb phrases.
