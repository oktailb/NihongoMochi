The Nai-form (ない形) - เชิงลบอย่างไม่เป็นทางการ

The นายฟอร์ม is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. วิธีการผันคำกริยา

การผันคำกริยาขึ้นอยู่กับกลุ่มกริยา จับตากลุ่ม 1 ให้ดี!

กลุ่มที่ 1: U-กริยา (Godan)

Change the final "คุณ" sound of the dictionary form to the corresponding "ก" sound, then add นะอิ.

  • 書く (kaku) → 書คะ + ない = 書かない (kakanai) - Not write
  • 飲む (nomu) → 飲มะ + ない = 飲มะนะอิ (nomanai) - Not drink
  • 話เลย (hanasu) → 話さ + ない = 話さない (hanasanai) - Not speak

⚠️ กฎพิเศษ: If the verb ends in a plain ü (คุณ), it changes to わ (วา), not 'a'.

  • 買เอ่อ (kau) → 買わ + ない = 買わない (kawanai) - Not buy

กลุ่มที่ 2: Ru-กริยา (อิจิดัน)

Simply drop the final รู (รู) and add นะอิ.

  • 食べรุ (taberu) → รับประทานอาหาร (tabenai) - Not eat
  • 見รุ (miru) → 見ない (minai) - Not see

กลุ่มที่ 3: กริยาที่ไม่สม่ำเสมอ

จดจำสิ่งเหล่านี้อย่างระมัดระวัง (สังเกตการเปลี่ยนแปลงเสียงของ 'kuru'):

  • สุขุ (suru) → しない (shinai)
  • 来ru (kuru) → นะอิ (konai - pronounced โค-นาย)
  • あru (aru - to exist/have) → นะอิ (nai) (ผิดปกติโดยสิ้นเชิง!)

2. รูปแบบไวยากรณ์ทั่วไป

จำเป็นต้องมีแบบฟอร์ม Nai สำหรับโครงสร้างที่สำคัญเหล่านี้:

  1. การขอไม่ทำอะไรสักอย่าง (~นาอิเดะ กุดาไซ):
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. ภาระผูกพัน (~นะเคะเระบะนะริมะเซ็ง): "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. การทำบางสิ่งบางอย่างโดยไม่ทำอย่างอื่น (~zuni / ~naide):
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
