อนุภาคพื้นฐาน (助詞 - Joshi)

อนุภาคเป็นเครื่องหมายเล็กๆ ที่ตามหลังคำเพื่อระบุบทบาทในประโยค พวกมันคือ "กาว" ที่ใช้ยึดประโยคภาษาญี่ปุ่นไว้ด้วยกัน

1. เครื่องหมายหัวข้อ: ฮะ (วะ)

อนุภาคฮะ(เขียนว่า 'ฮ่า' แต่ออกเสียง 'วา') ระบุถึงหัวข้อของประโยค—สิ่งที่คุณกำลังพูดถึง

  • 私HA学生です。(วาตาชิวากาคุเซ เดซู) -สำหรับฉันฉันเป็นนักเรียน

2. ตัวแสดงหัวเรื่อง: が (ga)

ในขณะที่ฮะทำเครื่องหมายหัวข้อがทำเครื่องหมายวิชาเฉพาะที่กระทำการหรือมีคุณสมบัติ มักจะให้ข้อมูลใหม่ๆ

  • 猫が好きです。(เนโกะกาsuki desu) - ฉันชอบแมว (ตัวอักษร: Cats are likable)
  • だれが来ましたか？ (กล้ากาคิมาชิตะ คะ?) -WHOมา?

3. เครื่องหมายวัตถุ: を (wo)

อนุภาคを(ออกเสียงว่า 'o') เครื่องหมายวัตถุโดยตรง- สิ่งที่กระทำโดยคำกริยา

  • รินโกโวทาเบมาสึ) - ฉันกินแอปเปิ้ล.

4. จุดหมายปลายทาง/เครื่องหมายเวลา: に (พรรณี)

อนุภาคอเนกประสงค์นี้บ่งบอกถึงทิศทาง, เวลาที่กำหนด, หรือที่ตั้ง(ของการดำรงอยู่).

  • 日本に行คิมาซู.(นิฮงพรรณีอิคิมัส) - ฉันไปล่ะถึงญี่ปุ่น.
  • 八時に起きまし。(ฮาจิจิพรรณีโอคิมัส) - ฉันตื่นแล้วที่8 โมง.

5. สถานที่ดำเนินการ: で (de)

บ่งชี้ที่ไหนการกระทำเกิดขึ้นหรือหมายถึง/เครื่องมือเคยทำอะไรบางอย่าง

  • 学校で勉強しまし。(กักโคเดอเบ็นเคียว ชิมาสุ) - ฉันเรียนอยู่ที่โรงเรียน.
  • ペンで書きまし。(ปากกาเดอคาคิมาสุ) - ฉันเขียนกับปากกา

6. เครื่องหมายการครอบครอง/ความสัมพันธ์: の (ไม่ใช่)

บ่งชี้การครอบครองหรือเชื่อมคำนามสองคำเข้าด้วยกัน มันทำงานเหมือนกับ "'s" ในภาษาอังกฤษ

  • 私の本 (วาตาชิเลขที่ที่รัก) -ของฉันหนังสือ.
  • 日本語の先生 (นิฮงโกะเลขที่อาจารย์) -ญี่ปุ่นครู.
