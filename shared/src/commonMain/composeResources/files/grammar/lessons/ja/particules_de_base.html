基本粒子 (助詞じょし） - まとめ

助詞は日本語の「接着剤」です。これらは単語の後に続き、文内での文法的役割を示します。

1. トピック: は

文が何について述べているのかを特定します（発音わ）。

  • 私わたしは学生がくせいです。
    （私に関して言えば、私は学生です。）

2. 件名: が

アクションの特定の実行者にスポットライトを当てます。

  • 猫ねこがあります。
    （猫がいます。）

3. 直接目的語: を

作用されるものをマークします（発音ああ）。

  • 水みずを飲のみます。
    (私は水を飲みます。)

4. 目的地と時間: に

どこへ行くのか、または特定の時点を示します。

  • 日本にほんに行いきます。
    （私は日本に行きます。）
  • 三時さんじに会ああります。
    (3時に集合します。)

5. 行動の場所と手段: で

アクションが発生する場所または使用されるツールを示します。

  • 学校がっこうで勉強べんきょうします。
    （私は学校で勉強します。）
  • ハシで食たべます。
    （私はお箸を使って食べます。）

6. 所有とつながり: の

2 つの名詞を接続します (「's」や「of」など)。

  • 私わたしの本ほん
    (私の本)

7. 早見表

粒子 役割 例
は トピック 私わたしは...
が 主題 誰だれが...
を 物体 本ほんを...
に 目標・時間 日本にほんに...
で 場所・道具 店みせで...
の 繋がり 日本にほんの...
