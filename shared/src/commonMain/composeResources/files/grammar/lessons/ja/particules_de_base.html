基本粒子 (助詞 - Joshi)

助詞は、文内での役割を示すために単語の後に続く小さなマーカーです。それらは日本語の文章をまとめる「接着剤」です。

1. トピックマーカー: 「は」

粒子は(「ハ」と書きますが、「ワ」と発音します)トピック文の内容 - あなたが話していること。

  • 私は学生です。(ワタシわ学生です) -私に関して言えば、 私は学生です。

2. 件名マーカー: が (ga)

その間はトピックをマークし、がをマークします特定の主題アクションを実行するか、性質を持っているもの。新しい情報を提供してくれることも多いです。

  • 猫が好きです。(猫が好きです) - 私は猫が好きです (直訳: 猫は好きです)。
  • だれが来ましたか？がきましたか?) -誰が来た?

3. オブジェクトマーカー: を

粒子を(「オー」と発音) は、直接目的語—動詞によって作用されるもの。

  • リンゴを食べます。(リンゴを食べます） - 食べますリンゴ。

4. 目的地/時間マーカー: に (ni)

この多用途な粒子が示すのは、方向、特定の時間、 または位置（存在の）。

  • 日本に行きます。にいきます) - 行きますに日本。
  • 八時に起きます。にオキマス) - 目が覚めますで8時。

5. 行動の場所: で (de)

を示しますどこアクションが発生するか、手段/ツール何かをしていた。

  • 学校で勉強します。デ勉強します） - 勉強しますで学校。
  • ペンで書きます。(ペンデかきます） - 書きますとペン。

6. 所有/関係マーカー: の (いいえ)

を示します所持または 2 つの名詞を接続します。英語の「's」のような働きをします。

  • 私の本いいえホン) -私の本。
  • 日本の先生 (日本語)いいえ先生） -日本語教師。
