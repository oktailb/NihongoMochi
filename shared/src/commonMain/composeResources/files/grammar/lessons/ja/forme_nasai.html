命令を与える: ～なさい

の～そうなのフォームは、しっかりした命令や指示を与えるために使用されます。文法的には丁寧ですが（敬語から派生したもの）、ナサル）、権威の強い雰囲気が漂います。通常、親から子供へ、教師から生徒へ、または筆記試験の指示で使用されます。

1.活用方法

添付するそうだねに直接動詞の語幹(前の部分～ます）。

[動詞語幹] + なさい

  • 食たべます →食たべ+そうな=食たべなさい（食べる！）
  • 行いきます →行いき + なさい =行いきなさい（行く！）
  • します → し + なさい =しなさい(やってみろ!)

2. 主要な例

  • 「もう遅おそから、早はやく寝ねそうだね。」
    (「もう遅いので、寝る素早く。"）
  • 「テレビを消けして、宿題しゅくだいをしなさい。」
    （「テレビを消して、するあなたの宿題。」）
  • 「つぎの」質問しつもんに答こたええやん。」
    ("答え次の質問です。」）

3. ニュアンス: 使用しない場合

なぜなら～そうなの話し手が聞き手に対して権限を持っているという明確な階層構造を暗示します。一度もない目上の人（上司、先生）や知らない人に対して使います。そのような場合には、～てくださいリクエスト用に。

4. 簡単なヒント: ～なさい vs ～ろ (命令的)

  • ～そうだ:しっかりしていて権威がありますが、「矯正」または教育的な方法（親、教師）で使用されます。
  • ～ろ（命令形）：非常に乱暴、攻撃的、または緊急時に使用されます。よりもはるかに厳しいように聞こえます～ナサイ。
