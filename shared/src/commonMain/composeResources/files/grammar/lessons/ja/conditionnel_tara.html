-Tara 条件文 (~たら)

The ~タラ conditional is the most common and versatile way to say "if" or "when" in Japanese. It is used to describe a condition that must be met before another action can happen.

1.活用方法

The rule is simple: Take the タ形 (informal past) of a verb, adjective, or noun, and add ら（ら）.

動詞

  • 行く (iku - to go) → 行った (itta) → 行ったら (ittara) - If I go / When I go
  • 食べる (taberu - to eat) → 食べた (tabeta) → 食べたら (tabetara) - If I eat / When I eat
  • する (suru - to do) → した (shita) → したら (shitara) - If I do

形容詞

  • I-形容詞: Replace the final ~i with ～カッタラ.
    安い (yasui - cheap) → 安かったら (yasukattara) - If it is cheap.
  • な-形容詞: Add ～だったら.
    暇 (hima - free time) → 暇だったら (hima dattara) - If you are free.

名詞

Like Na-adjectives, add ～だったら.

  • 雨 (ame - rain) → 雨だったら (ame dattara) - If it rains.

2.いつ使用しますか?

  1. 仮定の「もしも」: When something might happen.
    お金があったら、車を買います。(Okane ga attara, kuruma wo kaimasu) - If I had money, I would buy a car.
  2. 時間的な「いつ」: When the condition is certain to happen in the future.
    家に着いたら、電話して。(Ie ni tsuitara, denwa shite) - When you get home, call me.

3. 重要な注意事項

The event in the ~タラ clause must happen 初め. You cannot use ~タラ for things happening at the same time.
