ない形 (ない形) - 非公式の否定

The ない形 is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1.活用方法

活用は動詞グループによって異なります。グループ1に注目！

グループ 1: U-Verbs (Godan)

Change the final 「う」 sound of the dictionary form to the corresponding 「あ」 sound, then add ない.

  • 書く (kaku) → 書か + ない = 書けない (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 飲めない (nomanai) - Not drink
  • 話す (hanasu) → 話さ + ない = 話さない (hanasanai) - Not speak

⚠️特別ルール: If the verb ends in a plain う（う）, it changes to わ（わ）, not 'a'.

  • 買う (kau) → 買わ + ない = 買わない (kawanai) - Not buy

グループ 2: Ru-Verbs (一段)

Simply drop the final る（る） and add ない.

  • 食べる (taberu) → 食べない (tabenai) - Not eat
  • 見る (miru) → 見ない (minai) - Not see

グループ 3: 不規則動詞

これらを注意深く覚えてください（「くる」の音の変化に注意してください）。

  • する (suru) → しない (shinai)
  • 来る (kuru) → 来ない (konai - pronounced こーない)
  • ある (aru - to exist/have) → ない (nai) (完全にイレギュラー！)

2. 一般的な文法パターン

Nai 形式は次の重要な構造に必要です。

  1. 何かをしないでください（〜ないでください）：
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. 義務（〜ならなければなりません）： "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. 別のことをせずに何かをする (~zuni / ~naide):
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
