Potential Form (可能形) - 「できる」

The 潜在的な形式 is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1.活用方法

グループ 1: U-Verbs (Godan)

Change the final 「う」 sound to the 「え」 sound and add る（る）.

  • 行く (iku - go) → 行け + る = 利用可能 (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

グループ 2: Ru-Verbs (一段)

Replace the final る（る） with られる（られる）.

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

注:多々な会話では、「ら」が省略されることが多く、「食べられる」となります。

グループ 3: 不規則動詞

  • する (suru) → できる (dekiru) - Can do (全く違う！)
  • 来る (kuru) → 来られる (korareru) - Can come

2. 重要なパーティクルの変更

When using the potential form, the object particle を（を） often changes to が（が）.

  • (私は日本語を話します。)
  • 日本語が話せます。(I できる speak Japanese.)

3.「Potential Form」vs「～ことができる」

Both mean "can do", but the potential form is more common in daily conversation, while ことができる is slightly more formal or used for long verb phrases.
