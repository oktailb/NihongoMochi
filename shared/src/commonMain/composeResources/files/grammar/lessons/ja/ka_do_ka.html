間接的な質問: ～か、～かどうか

日本語では、大きな文の中に質問を埋め込んで、「... かどうかわかりません」または「... かどうか確認します」のように言うことができます。使用する形式は、質問に疑問詞 (「誰が」または「何を」など) があるかどうかによって異なります。

1. 疑問詞を使った質問（誰が、何を、どこで…）

を使用します。プレーンなフォルム動詞/形容詞の後に続くか。

  • 何なにを食たべるか、決きめてない。
    (決めてないよ何食べます。）
  • いつでも日本にほんへ行いくか、教おし食べてください。
    （教えてくださいいつあなたは日本に行きます。）

2. はい/いいえの質問: ～かどうか

疑問詞がない場合（例：「かどうか」）、を使用します。～かどうか。

  • おいしいかどうか、分かりません。
    （わからないかどうかおいしいですよ。）
  • 明日あした暇ひまかどうか、聞きいてみます。
    (聞いてみますかどうか[彼は]明日は暇です。)

3. 文章の構造

タイプ 繋がり
動詞 / い-Adj 普通形 + か / どうか
な-形容詞 / 名詞 名詞（いいえだ) + か / どうか

4. この構造で使用される一般的な動詞

このパターンの後には、ほとんどの場合、次の動詞が続きます。知っている、チェック中、 または決める:

  • 理解する（知る/理解する）
  • 知る（知る）
  • しらべる（調べる・調べる）
  • きめる（決める）
  • おぼえる
