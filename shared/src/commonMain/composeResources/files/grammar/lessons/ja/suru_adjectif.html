変更を加える：形容詞を使って～する

一方、動詞ナル「なる」（自然な変化）を意味する動詞する誰かがいるときに使用されます意図的に変化を起こします。これは「[何か]...を作る」または「[何か]を...に変える」と訳されます。

1. な形容詞と名詞の場合

パーティクルを追加するに前にする。

  • 部屋へやを綺麗きれいにします。
    (部屋をきれいにします / 部屋を掃除します。)
  • 音おとを静しずかしてください。
    (静かにしてください/音を静かにしてください。)

2. I-形容詞を使って

ファイナルを交換する～いと～く前にする。

  • テレビの音おとを大おおきくしました。。
    （テレビの音量を大きくしました。）
  • 何安やすしてくれませんか。
    （もっと安くしてもらえませんか？）

3. 概要表

タイプ 繋がり 例
名詞 名詞 +にする 半分はんぶん半分にする
な-形容詞 調整+にする 親切しんせつする（親切にしてください）
い-Adj 形容詞 (マイナスい) +くする 早はや早くする

4. 区別: なる vs する

  • ～になる / ～になる:状態が勝手に変わった（部屋になったクリーン）。
  • ～する / ～する:誰か引き起こされた変化（私は作った部屋はきれいです）。
