条件付き活用 (仮定形かていけい)

の～ばform は条件文 (if.​​..) を作成するために使用されます。その形成をマスターすることは、「the more... the more...」のような高度な文法パターンに不可欠です。

1. 動詞

グループ 1: U-Verbs (Godan)

決勝を変える「う」対応する音「え」音を出して追加するば。

  • 行いく → 行いもしあれば
  • 話はなす → 話はなそうです
  • 飲のむ → 飲のめば

グループ 2: Ru-Verbs (一段)

ファイナルを交換するるとあれば。

  • 食たべる → 食たべれば
  • 見みる → 見れば

グループ 3: 不規則動詞

  • する →あれば
  • 来くる→来くあれば(発音したくれば)

2. 形容詞

私-形容詞

ファイナルを交換する～いと～あれば。

  • 暑あつ私 → 暑あつもしあれば
  • 安やす私 → 安やすもしあれば
  • いいですね(良い) →よければ(不定期)

な形容詞と名詞

追加なら（ば）またはあれば。

  • 暇ひま → 暇ひまもし
  • 学生がくせい → 学生がくせいもし

3. 否定動詞

「[one] がそうでない場合」と言うには、～いのない形と～あれば。

  • 行いない →行いかなもしあれば(行かなかったら)
  • 食たべない →食たべなもしあれば(食べないと)
