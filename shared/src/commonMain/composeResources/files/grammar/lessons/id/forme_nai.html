Bentuk Nai (ない形) - Negatif Informal

The Bentuk Nai is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. Cara Konjugasi

Konjugasi tergantung pada kelompok kata kerja. Perhatikan baik-baik Grup 1!

Kelompok 1: U-Verba (Godan)

Change the final "kamu" sound of the dictionary form to the corresponding "A" sound, then add ない.

  • 書く (kaku) → 書か + ない = 書かない (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 飲まない (nomanai) - Not drink
  • 話す (hanasu) → 話さ + ない = 話さない (hanasanai) - Not speak

⚠️ Aturan Khusus: If the verb ends in a plain う (kamu), it changes to わ (wa), not 'a'.

  • 買う (kau) → 買わ + ない = 買わない (kawanai) - Not buy

Grup 2: Kata Kerja Ru (Ichidan)

Simply drop the final る (ru) and add ない.

  • 食べる (taberu) → 食べない (tabenai) - Not eat
  • 見る (miru) → itu (minai) - Not see

Kelompok 3: Kata Kerja Tidak Beraturan

Hafalkan ini dengan cermat (perhatikan perubahan suara untuk 'kuru'):

  • する (suru) → しない (shinai)
  • 来る (kuru) → 来ない (konai - pronounced ko-nai)
  • ある (aru - to exist/have) → ない (nai) (Benar-benar tidak teratur!)

2. Pola Tata Bahasa Umum

Bentuk Nai diperlukan untuk struktur penting berikut:

  1. Permintaan untuk tidak melakukan sesuatu (~naide kudasai):
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. Kewajiban (~nakereba narimasen): "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. Melakukan sesuatu tanpa melakukan yang lain (~zuni / ~naide):
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
