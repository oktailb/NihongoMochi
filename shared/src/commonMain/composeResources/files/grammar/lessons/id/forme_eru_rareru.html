Bentuk Potensial (可能形) - "Dapat melakukan"

The Bentuk Potensial is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. Cara Konjugasi

Kelompok 1: U-Verba (Godan)

Change the final "kamu" sound to the "e" sound and add る (ru).

  • 行く (iku - go) → 行け + る = itu (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲める (nomeru) - Can drink

Grup 2: Kata Kerja Ru (Ichidan)

Replace the final る (ru) with られる (jarang).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → られる (mirareru) - Can see

Catatan: Dalam percakapan santai, "ra" sering dihilangkan: 食べれる (tabereru).

Kelompok 3: Kata Kerja Tidak Beraturan

  • する (suru) → できる (dekiru) - Can do (Sangat berbeda!)
  • 来る (kuru) → 来られる (korareru) - Can come

2. Perubahan Partikel Penting

When using the potential form, the object particle を (wo) often changes to が (ga).

  • 日本語を話します。(Saya berbicara bahasa Jepang.)
  • 日本語が話せます。(I Bisa speak Japanese.)

3. "Bentuk Potensial" vs "~koto ga dekiru"

Both mean "can do", but the potential form is more common in daily conversation, while koto ga dekiru is slightly more formal or used for long verb phrases.
