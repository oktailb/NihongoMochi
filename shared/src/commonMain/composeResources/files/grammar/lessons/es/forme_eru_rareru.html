La forma potencial (可能形) - "Puedo hacer"

The Forma potencial is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. Cómo conjugar

Grupo 1: Verbos U (Godan)

Change the final "tú" sound to the "mi" sound and add る (ru).

  • 行く (iku - go) → 行け + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 話せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 飲 め る (nomeru) - Can drink

Grupo 2: Ru-Verbos (Ichidan)

Replace the final る (ru) with られる (rareru).

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 見られる (mirareru) - Can see

Nota: En el habla informal, a menudo se omite la "ra": 食べれる (tabereru).

Grupo 3: Verbos irregulares

  • する (suru) → できる (dekiru) - Can do (¡Completamente diferente!)
  • 来る (kuru) → 来られる (korareru) - Can come

2. Cambio importante de partículas

When using the potential form, the object particle を (dos) often changes to が (ga).

  • 日本語を話します。(Hablo japonés).
  • 日本語が話せます。(I poder speak Japanese.)

3. "Forma potencial" frente a "~koto ga dekiru"

Both mean "can do", but the potential form is more common in daily conversation, while koto ga dekiru is slightly more formal or used for long verb phrases.
