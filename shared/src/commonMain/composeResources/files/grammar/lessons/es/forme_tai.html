Expresando deseo: ~Tai (~たい)

El~ taiLa forma se utiliza para expresar lo que el hablantequiere hacer. Sólo se utiliza para sus propios deseos o cuando le pregunta directamente a otra persona qué quiere.

1. Cómo conjugar

El~ taiEl final se une a laraíz verbal(la parte anterior~masu).

Grupo 1: Verbos U (Godan)

Cambie la "u" final por "i" y agregueたい.

  • 行く (iku) → 行き (iki) →行きたい(ikitai) - Quiero ir
  • 飲む (nomu) → 飲み (nomi) →飲みたい(nomitai) - Quiero beber

Grupo 2: Ru-Verbos (Ichidan)

quitar la finalる (ru)y agregarたい.

  • 食べる (taberu) →食べたい(tabetai) - Quiero comer
  • 見る (miru) →見たい(mitai) - Quiero ver

Grupo 3: Verbos irregulares

  • する (suru) →したい(shitai) - Quiero hacer
  • 来る (kuru) →来たい(kitai) - Quiero venir

2. ¡Se comporta como un adjetivo I!

Una vez que agregas~ tai, la palabra se conjuga exactamente como unaI-adjective.

  • Afirmativo:行きたいです (Quiero ir)
  • Negativo:行きたくないです (No quiero ir)
  • Pasado:行きたかったです (quería ir)
  • Negativo pasado:行きたくなかったです (No quería ir)

3. Uso de partículas

Con~ tai, puedes usar cualquieraをoがpara marcar el objeto, aunqueがA menudo enfatiza el objeto del deseo.

  • 水を飲みたい。(Mizu wo nomitai) - Quiero beber agua.
  • 水が飲みたい。(MizuGeorgianomitai) - quiero beberagua(específicamente).
