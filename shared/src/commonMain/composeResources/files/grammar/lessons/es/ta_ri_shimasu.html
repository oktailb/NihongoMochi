Acciones de listado: ~Tari ~Tari (~たり ~たり)

El~tari ~tari suruLa estructura se utiliza para enumerar dos o más acciones de un conjunto más amplio de actividades. Implica "hacer cosas como A y B (entre otras)".

1. Cómo darle forma

Toma elforma ta(pasado informal) del verbo y agregarり (ri). Siempre termina la oración con el verbo.する (suru)para indicar el nivel de tiempo y cortesía.

Ejemplos:

  • 読む (yomu - leer) → 読んだ (yonda) →読んだり(yondari)
  • 聞く (kiku - escuchar) → 聞いた (kiita) →聞いたり(kiitari)

2. Uso en una oración

[Acción A]たり、[Acción B]たり します。

  • 休みの日は、映画を見たり、本を読んだりします。(Yasumi no hi wa, eiga wo mitari, hon wo yondari shimasu) - En mis días libres, hago cosas como ver películas y leer libros.
  • 昨日は、買い物をしたり、 友 達 に会 っ た りしました。(Kinou wa, kaimono wo shitari, tomodachi ni attari shimashita) - Ayer hice cosas como ir de compras y reunirme con amigos.

3. Diferencias importantes

Estructura Significado Matiz
～て、～て (forma Te) A, luego B Orden secuencial (exhaustivo)
～たり、～たり (forma tari) A y B (etc.) Lista no exhaustiva (orden aleatorio)

4. Adjetivos y sustantivos

También puedes usar esto con adjetivos y sustantivos (aunque es menos común para N5):

  • 暑かったり、寒かったりします。(Atsukattari, samukattari shimasu) - A veces hace calor, a veces hace frío.
