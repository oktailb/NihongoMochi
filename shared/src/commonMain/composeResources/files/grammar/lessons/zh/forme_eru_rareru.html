潜在形式 (可能形) - “可以做”

The 潜在形式 is used to express that someone has the ability to do something, or that a situation allows for an action to happen.

1. 如何结合

第一组：U-动词（Godan）

Change the final “你” sound to the “e” sound and add る (ru).

  • 行く (iku - go) → 行け + る = 行ける (ikeru) - Can go
  • 話す (hanasu - speak) → 話せ + る = 话せる (hanaseru) - Can speak
  • 飲む (nomu - drink) → 飲め + る = 饮める (nomeru) - Can drink

第 2 组：Ru-动词（Ichidan）

Replace the final る (ru) with られる（稀有）.

  • 食べる (taberu) → 食べられる (taberareru) - Can eat
  • 見る (miru) → 见られる (mirareru) - Can see

注意：在懒讲话中，“ra”经常被简洁：食べれる（tabereru）。

第三组：不规则动词

  • する (suru) → できる (dekiru) - Can do (完全不同！)
  • 来る (kuru) → 来られる (korareru) - Can come

2. 重要的粒子变化

When using the potential form, the object particle を（我） often changes to が（嘎）.

  • 日本语を话します。（我会说日语。）
  • 日本語が話せます。(I 能 speak Japanese.)

3.“潜在形态”vs“~koto ga dekiru”

Both mean "can do", but the potential form is more common in daily conversation, while 声音 is slightly more formal or used for long verb phrases.
