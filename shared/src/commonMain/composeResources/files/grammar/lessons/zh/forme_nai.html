Nai 形式 (ない形) - 非正式否定

The 奈形式 is used for the negative present tense in casual Japanese. It is also the building block for several important grammar structures like "must" or "please don't".

1. 如何结合

词形变化取决于动词组。密切关注第1组！

第一组：U-动词（Godan）

Change the final “你” sound of the dictionary form to the corresponding “一个” sound, then add ない.

  • 書く (kaku) → 書か + ない = 书かない (kakanai) - Not write
  • 飲む (nomu) → 飲ま + ない = 饮まない (nomanai) - Not drink
  • 話す (hanasu) → 話さ + ない = 话さない (hanasanai) - Not speak

⚠️特别规则： If the verb ends in a plain う (u), it changes to わ (wa), not 'a'.

  • 買う (kau) → 買わ + ない = 买わない (kawanai) - Not buy

第 2 组：Ru-动词（Ichidan）

Simply drop the final る (ru) and add ない.

  • 食べる (taberu) → 食べない (tabenai) - Not eat
  • 見る (miru) → 见ない (minai) - Not see

第三组：不规则动词

仔细记住这些（注意“kuru”的发音变化）：

  • する (suru) → しない (shinai)
  • 来る (kuru) → 来ない (konai - pronounced 科内)
  • ある (aru - to exist/have) → ない (nai) (完全不规则！)

2. 常见语法模式

这些基本结构需要 Nai 形式：

  1. 要求不要做某事（~naide kudasai）：
    忘れないでください。(Wasurenaide kudasai) - Please don't forget.
  2. 义务（~nakereba narimasen）： "Must do" (lit: If you don't do, it's no good).
    勉強しなければなりません。(Benkyou shinakereba narimasen) - I must study.
  3. 做某事而不做另一件事（~zuni / ~naide）：
    寝ないで勉強しました。(Nenaide benkyou shimashita) - I studied without sleeping.
