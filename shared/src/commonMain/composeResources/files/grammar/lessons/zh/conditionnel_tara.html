-Tara 条件式 (~たら)

The 〜塔拉 conditional is the most common and versatile way to say "if" or "when" in Japanese. It is used to describe a condition that must be met before another action can happen.

1. 如何结合

The rule is simple: Take the 塔型 (informal past) of a verb, adjective, or noun, and add ら (ra).

动词

  • 行く (iku - to go) → 行った (itta) → 行ったら (ittara) - If I go / When I go
  • 食べる (taberu - to eat) → 食べた (tabeta) → 食べたら (tabetara) - If I eat / When I eat
  • する (suru - to do) → した (shita) → したら (shitara) - If I do

形容词

  • I-形容词： Replace the final ~i with 〜卡塔拉.
    安い (yasui - cheap) → 安かったら (yasukattara) - If it is cheap.
  • Na-形容词： Add ～达塔拉.
    暇 (hima - free time) → 暇だったら (hima dattara) - If you are free.

名词

Like Na-adjectives, add ～达塔拉.

  • 雨 (ame - rain) → 雨だったら (ame dattara) - If it rains.

2.什么时候使用？

  1. 假设的“如果”： When something might happen.
    お金があったら、車を買います。(Okane ga attara, kuruma wo kaimasu) - If I had money, I would buy a car.
  2. 时间“何时”： When the condition is certain to happen in the future.
    家に着いたら、電話して。(Ie ni tsuitara, denwa shite) - When you get home, call me.

3. 重要提示

The event in the 〜塔拉 clause must happen 第一的. You cannot use 〜塔拉 for things happening at the same time.
